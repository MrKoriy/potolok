# Potolok Demo Websites

Репозиторий демонстрационных продуктов и веб-приложений для ниши натяжных потолков.

## Проекты

### [potolok-pwa](./potolok-pwa)
Полнофункциональное White-label PWA приложение для онлайн-расчета сметы и записи на замер натяжных потолков:
- **Интерактивный сметчик-конфигуратор**: площадь, фактуры полотен (MSD, Descor), теневой профиль EuroKRAAB, треки, световые линии, ниши ПК-5.
- **Онлайн-запись на замер**: выбор окон времени (2 часа) с буфером на дорогу и блокировкой пересечений.
- **Анонимный доступ клиента**: доступ к статусу замера по SHA-256 криптографическому токену без обязательной регистрации.
- **Кабинет замерщика и собственника**: мобильный интерфейс для корректировки сметы на объекте и отправки КП в мессенджер.
- **Конвейер брендинга за 6 минут**: скрипты генерации нового тенанта из карточки 2GIS/Яндекс Карт (`pnpm run tenant:new`).
- **Стек**: React 19, TypeScript, Vite, Tailwind CSS, vite-plugin-pwa, Supabase Postgres/RLS/Outbox.
